# v1.2.18 — VGE / Big and Small - Sapient Animals

## 적용 동작

### Vanilla Genetics Expanded

- 일반 교배 동물은 기존 육식성/몸집 조건과 곤충 허용 설정을 적용한다. 교배 동물을 전부 무조건 추첨 목록에 넣지는 않는다.
- 잠재 변신자 교배 동물을 각성시키면 교배 품질, 유전병 발생까지의 진행 시간, 품질에 따른 발생 시점, 기존 VGE 유전병 4종의 심각도를 원래 정착민에 저장한다. 다시 해당 동물로 변신하면 이를 복원한다. 인간으로 돌아온 동안 동물의 유전병 타이머는 진행하지 않는다.
- 일반 변신자로서 교배 동물 형상을 처음 배정받은 경우 VGE의 기본 품질을 사용한다. 변신으로 고품질을 무작위 재추첨하지 않는다.
- VGE 실험 실패체, 수명/초기화에 의존하는 형상, `AnimalGeneticMechanoid` 기계 교배체는 일반 변신 및 잠재 변신자 추첨에서 제외한다. 이전 저장에서 이런 형상을 배정받은 경우 다음 형상 유효성 검사에서 재배정될 수 있다.
- 일반 동물의 품질이나 VGE의 교배 성공률·제작·DNA 추출 규칙은 바꾸지 않는다.

### Big and Small - Sapient Animals

- B&S가 등록한 원래 동물 종을 조회한다. 이미 지성화된 동물이 새 변신자가 될 때 원래 종을 배정한다. 쥐처럼 일반 추첨 목록 밖에 있는 작은 동물도 자기 종으로 변신하고 원래 지성화된 몸으로 돌아올 수 있다. 기존에 유효한 다른 형상을 배정받은 변신자는 그대로 유지한다.
- 잠재 변신자에게 Cogni-Fi를 쓰면 B&S가 생성한 지성화된 동물 정착민을 유지하고 원래 동물 형상을 가진 변신자로 연결한다. 다시 무작위 인간을 생성하지 않는다. 평범한 동물에게 Cogni-Fi를 쓰는 것만으로 Wild Shift 능력을 부여하지 않는다.
- 변신 중인 동물에 Cogni-Fi를 써도 원래 정착민을 담은 보관 객체를 유지한다. 복귀 명령, 선택, 징집 상태를 이어간다. 옷·장비·짐·운반 물건은 바닥에 보존하며, 변신체의 바닥 배치가 실패하면 보관 중인 원래 정착민의 소지품으로 옮긴다.
- 지성화된 몸을 일반 잠재 동물로 오인해 수동 각성이나 치료 과정에서 다른 인간으로 교체하지 않는다.
- **Cogni-Fi는 사용한 몸을 지성화한다.** 임시 변신체에 사용한 뒤 원래 몸으로 복귀하면 다음 변신은 평소 동물 형상으로 생성된다. 모든 변신체를 자동으로 지성화하거나 원래 정착민의 작업 능력을 임시 지성체에 복사하는 기능은 포함하지 않는다.

### 두 모드 동시 사용

VGE가 동적으로 추가하는 품질·유전병 컴포넌트는 B&S 종족 생성보다 늦게 준비될 수 있다. 초기화가 끝난 뒤 한 번만 생성 종족의 해당 컴포넌트를 보완한다. Cogni-Fi 사용 전 품질·진행 상태를 캡처하고 지성화된 몸에 복원한다. 일반 VGE 교배 동물의 Cogni-Fi 변환에도 같은 상태 보존을 적용한다.

형상 선택/전환 시에만 연결 처리를 실행한다. 새 맵 전체 틱 스캔이나 별도 주기 작업을 추가하지 않는다. 지성화된 교배체의 유전병 시간은 VGE의 기존 컴포넌트가 진행한다.

## 검증 범위

RimWorld 1.6.4871 rev591의 실제 게임 프로세스를 별도 `-savedatafolder`로 실행한 회귀검사다. 플레이어의 원본 세이브와 활성 모드 설정은 수정하지 않는다. 배치 모드 검사는 데이터와 동작 검증이며 화면 렌더링 검증이 아니다.

검증 결과와 사용한 테스트 코드, 활성 모드 및 어셈블리 기록은 `wildshift-releas/verification/Compatibility-v1.2.18/`에 보관한다.

| 실제 게임 환경 | 통과한 검사 |
| --- | ---: |
| VGE + B&S Framework + Sapient Animals + 전체 DLC | 308 |
| VGE + VEF + 전체 DLC | 279 |
| B&S Framework + Sapient Animals + 전체 DLC | 20 |
| Core + Harmony만 사용 | 2 |

총 609개 검사가 통과했다. 각 환경에서 새 게임과 저장 후 별도 프로세스 재시작을 실행했다. VGE 형상 79종의 생성·원래 정착민 복귀, 제외 대상, 실제 각성 후 품질/유전병 복원, 인간 상태 및 지성화된 변신 상태의 저장·복귀를 확인했다. 79종은 이 테스트에서 곤충 형상을 허용한 결과이며 설치 구성에 따라 달라진다.

B&S 검사에는 작은 종인 쥐, 잠재 변신자, 평범한 동물, 징집된 변신체, VGE 교배체의 Cogni-Fi 전환과 원래 몸의 보관·복귀가 포함된다. 소지품과 갑옷 객체의 보존을 검사했으며, 갑옷의 화면 표시를 새로 검증한 것은 아니다. 검사 중 오류 파일과 실패 항목은 없었으며, 게임 로그에서 예외나 Wild Shift 오류가 검출되지 않았다. 초기 검증에서 발견한 B&S/VGE 초기화 순서 문제를 수정한 최종 DLL 기준이다.

기존 모형 기반 테스트 367개(종족/각성 선택 106, 안정성 246, 특수 훈련 15), Harmony 실제 패치 호출 검사 및 게임 API/XML 검사도 통과했다. 모형 테스트는 실제 게임 검사와 별개다.

## 기준 소스와 제한

- VGE: [제작자 저장소](https://github.com/Vanilla-Expanded/VanillaGeneticsExpanded), commit `78a03c3e3e03ca7518c1bd467d0100fa330cfd29`, 1.6.
- B&S Framework: 설치된 Workshop `2925432336`, 1.6 `BigAndSmall.dll`.
- Sapient Animals: 설치된 [Workshop 3505241400](https://steamcommunity.com/sharedfiles/filedetails/?id=3505241400), `RedMattis.SapientAnimals`.
- 두 모드와 각자의 선행 모드를 먼저 로드하고 Wild Shift를 뒤에 배치한다. 선택 호환이며 필수 의존성을 추가하지 않는다. 제3자 DLL·텍스처·정의를 Wild Shift 배포물에 포함하지 않는다.
- 동물 생산물, 개별 임플란트, 임의의 제3자 컴포넌트 전체를 형상 사이에 복제하지 않는다. B&S의 종별 작업 제한·렌더 트리·자체 능력 변환 규칙은 유지한다. VGE 굴파기 동물 등 B&S가 별도 경고하는 렌더 트리의 외형은 이 버전에서 검증하지 않았다.
- v1.2.18 이전에 이미 지워진 교배 품질/유전병 정보는 복구할 수 없다. 이후 각성·복귀 시점부터 기록한다. 이전부터 변신 중인 교배체는 현재 몸의 정보를 다음 정상 복귀에서 기록한다.
