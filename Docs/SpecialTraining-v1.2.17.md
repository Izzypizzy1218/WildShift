# v1.2.17 특수 훈련 및 군락여왕 알림 수정

## 적용 동작

- 변신한 동물은 해당 종의 `race.specialTrainables`에 등록된 훈련과 유효한 선행 훈련을 완료한 상태로 시작한다. 게임의 훈련 가능 여부도 확인하며, 다른 종의 특수 훈련은 부여하지 않는다.
- 기존 저장에서 이미 동물 상태인 변신자도 불러오기가 끝나면 같은 기준으로 보정한다. 원래 훈련 저장 형식을 사용하며 새 저장 필드는 추가하지 않는다.
- 특수 훈련이 있는 변신체는 인간의 정신을 유지하므로, 해당 동물 몸에 있는 훈련의 자연 퇴화를 중단한다. 주기적으로 훈련을 다시 채우는 방식이 아니다. 특수 훈련이 없는 형상과 일반 동물은 기존 훈련 퇴화를 따른다.
- 군락여왕의 `EggSpew` 훈련이 완료되어 자동 알·점액 분사가 중단된다. 수동 능력과 기존 재사용 대기시간 등은 유지된다. 이미 맵에 만들어진 알이나 점액은 제거하지 않는다.
- 새 변신체의 발견 알림만 생략한다. 야생 군락여왕의 발견 알림, 일반 동물의 훈련, 도감 발견 처리, 퀘스트 신호, 공개 여부 저장은 유지한다.

## 실제 게임 엔진 검사

RimWorld 1.6.4871 rev591, Harmony, Core 및 공식 DLC, Wild Shift와 검사 전용 모드를 사용했다. 별도 저장 경로에서 실행했고 사용자 세이브는 사용하지 않았다.

- 실제 v1.2.16으로 생성한 미훈련 군락여왕 저장을 수정 DLL로 불러와 2/2 자동 완료를 확인했다.
- 인간 복귀 후 재변신, 강제 훈련 퇴화, 수정본에서 다시 저장하고 프로세스를 재시작해 불러오기까지 확인했다.
- 변신체 자동 분사 억제, 수동 능력 보존, 반복 발견 알림 억제와 원래 공개 플래그 유지가 통과했다.
- 일반 군락여왕은 미훈련·자동 분사·발견 알림·훈련 퇴화가 그대로 유지되는 것을 확인했다.
- 종별 특수 훈련이 있는 바닐라 변신 후보 **22종**에서 최초 변신 및 저장 불러오기 후 훈련 완료, 선행 훈련, 다른 종의 훈련 미부여를 검사했다.
- 위 수정본 검사 **504개**가 통과했다. 이전 DLL로 만든 저장의 사전 조건 검사 3개는 별도로 보관한다.
- 공식 DLC를 모두 비활성화한 Core 전용 환경에서도 로딩·변신·훈련 처리·공개 처리·인간 복귀 검사 4개가 통과했다. Odyssey는 필수 의존성이 아니다.

자동 분사 검사는 같은 난수 시드로 네이티브 `CompSpreadSludge.CompTick`을 150,000회 호출하고 `Verb.TryStartCastOn` 진입을 관측했다. 변신체에서 0회, 미훈련 일반 군락여왕에서 8회였다. 실제 시간 동안 낳은 알 개수나 렌더링 검사 수치가 아니다.

발견 알림은 `FogGrid.Unfog`를 호출해 검사했다. 공개된 맵에서 변신 직후에는 알림이 자동으로 뜨지 않을 수 있다. 원래 제보의 정확한 알림 문구는 확인되지 않았으며, 이번 수정은 별도로 재현한 군락여왕 발견 알림 경로를 처리한다.

라바도 같은 종류의 자동 분사 억제 로직을 사용하지만, 현재 기본 종족 정의에서는 Wild Shift의 변신 후보가 아니다. 이 업데이트는 변신 후보 목록을 바꾸지 않는다.

## 회귀 검사와 성능 범위

- 기존 안정성 246개, 형상 선택 등 로직 89개, 각성 종족 선택 17개가 통과했다.
- 새 특수 훈련 도우미 검사 15개가 통과했다. 공유 선행 조건, 중복 초기화, 지원하지 않는 훈련과 선행 조건, 순환 참조, 일반 동물 제외 등을 포함한다.
- 실제 게임 DLL 메타데이터로 Harmony 대상 35개, 주입 필드 10개, 기존 적 관련 정확한 시그니처 10개 및 XML/참조를 확인했다.
- 훈련 완료는 새 몸 생성과 저장 불러오기에서만 실행한다. 훈련 퇴화 차단은 원래 250틱 간격으로 호출되는 훈련 메서드에서 해당 개체만 판별하며 전체 맵/훈련 정의 순회나 할당을 추가하지 않는다.
- 발견 알림 패치는 원본 메서드의 해당 알림 컴포넌트 조회 한 곳만 바꾼다. 예상 호출을 찾지 못하면 원본을 유지하고 오류를 기록한다.
- 설치한 모든 제삼자 모드의 별도 훈련 시스템까지 검사한 것은 아니다. 게임의 종별 특수 훈련 목록과 표준 훈련 API를 사용하는 정의를 지원한다.
