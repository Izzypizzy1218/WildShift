# RimWorld 1.7 assembly regression host

Run `Tests/Run-Runtime17Tests.ps1` after building `1.7/Assemblies/WildShift.dll`.
The runner accepts `-RimWorldDir`, `-HarmonyPath`, `-WildShiftPath`, `-DotNet`,
and `-Output` overrides. It requires the .NET 10 SDK and the actual RimWorld
1.7 / Harmony 1.7 assemblies. No game or Harmony binaries are redistributed.

This console host checks the compiled mod, rather than compiling replacement
RimWorld API stubs. Its current checks cover:

- `Harmony.PatchAll` registration of every declared WildShift patch, including
  the native drag-selection local function, and injected field compatibility.
- XML parsing, duplicate definitions/translation keys, and native think-tree
  names and node types used by the mod.
- Real patched player-control and drag-priority getters for a transformed
  player animal, an ordinary animal, and an enemy form.
- The native ranged/melee-choice guard for a form without equipment, invalid
  melee target rejection, and prevention of overlapping return operations.
- Native `ThingOwner` identity/ownership preservation and idempotent storage.
- Native Scribe save/load of the production transformed-body storage using a
  minimal native Pawn identity subgraph: body ID, name, race, kind, single
  ownership, enemy flags, and release after reload.
- Absence of errors in the native log generated by these checks.

All temporary configuration, serialized fixture data, build output, and logs
are written under the selected scratch output (by default
`../.tmp/wildshift-17-tests`). The host does not launch RimWorld, load a colony,
change the user's configuration/saves, initialize Steam, or install mods.
It reads installed Core/DLC metadata, but its fixture enables Core only.

The pawn subgraphs intentionally omit unrelated map, rendering, and gameplay
trackers. This is **not** a complete map transformation/reversion, colony-save
round-trip, visual melee-button check, or third-party-mod integration test.
Those require a separate actual-game fixture; do not describe this run as
proof that every installed mod combination works.
